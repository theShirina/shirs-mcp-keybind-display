# Changelog

## 0.1.0

### Added

- Added a standalone HUD that lists Microbot Control Panel actions and their assigned keys, including actions registered later by the panel.
- Added settings to filter actions, choose which ones appear, adjust the HUD, and launch settings from a minimap button.
- Added a keybind editor for replacing or clearing WoW bindings, with confirmation before overwriting existing keys and recovery warnings when a change cannot be fully restored.
